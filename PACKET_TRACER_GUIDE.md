# NetArchitect: Cisco Packet Tracer Lab Recreation & Verification Guide

This guide provides step-by-step instructions for network students, evaluators, and lab instructors to recreate the network architectures generated by **NetArchitect** inside **Cisco Packet Tracer** (version 8.0 or later).

---

## 1. Required Cisco Packet Tracer Hardware Models

| NetArchitect Logical Device | Recommended Packet Tracer Model | Packet Tracer Device Category |
|---|---|---|
| **Border / Edge Router** | Cisco 4331 or Cisco 2911 ISR Router | Network Devices &rarr; Routers |
| **Core / Distribution Switch** | Cisco Catalyst 3650-24PS (Multilayer) | Network Devices &rarr; Switches |
| **Layer 2 Access Switch** | Cisco Catalyst 2960-24TT | Network Devices &rarr; Switches |
| **Wireless Access Points** | AccessPoint-PT / WAP-300N | Network Devices &rarr; Wireless Devices |
| **Client Workstations** | PC-PT / Laptop-PT | End Devices &rarr; PC |
| **Datacenter Servers** | Server-PT | End Devices &rarr; Server |

---

## 2. Recreating Scenario 1: Campus LAN (3-Tier Hierarchical)

### Step 1: Place Hardware on the Canvas
1. **Core Layer:** Add two `3650-24PS` Multilayer Switches and name them `CORE-SW01` and `CORE-SW02`.
2. **Distribution Layer:** Add two `3560-24PS` or `3650-24PS` switches per building (`DIST-BLD1`, `DIST-BLD2`, `DIST-BLD3`).
3. **Access Layer:** Add three `2960-24TT` switches (`ACC-BLD1`, `ACC-BLD2`, `ACC-BLD3`).
4. **Border Gateway:** Add one `4331` or `2911` router (`EDGE-RTR01`).
5. **Endpoints:** Place 3 PCs on `ACC-BLD1`, 2 PCs and 1 Server on `ACC-BLD2`.

### Step 2: Cable Interconnections
- **Inter-Core Link (LACP):** Connect `GigabitEthernet1/0/47` and `GigabitEthernet1/0/48` between `CORE-SW01` and `CORE-SW02` using Copper Cross-Over cables.
- **Distribution Uplinks:** Connect each Distribution switch to both `CORE-SW01` and `CORE-SW02` using Copper Straight-Through cables (or Fiber SFP modules).
- **Access Uplinks:** Connect `GigabitEthernet1/0/49` on `ACC-BLD1` to `GigabitEthernet1/0/1` on `DIST-BLD1`.
- **Router Downlink:** Connect `GigabitEthernet0/0/0` on `EDGE-RTR01` to `GigabitEthernet1/0/1` on `CORE-SW01`.

### Step 3: Apply Generated Configurations
1. In NetArchitect, click on the **Cisco Configs** tab.
2. Select **Core/Distribution Switch**, copy the script, and in Packet Tracer click on `CORE-SW01` &rarr; **CLI** tab &rarr; paste the script.
3. Select **Access Switch**, copy the script, and paste into `ACC-BLD1` CLI.
4. Select **Border / Edge Router**, copy the script, and paste into `EDGE-RTR01` CLI.

## 3. Cisco IOS Verification Commands

Open the CLI of `CORE-SW01` in Packet Tracer and execute:

### 1. Verify VLAN Database Creation:
```cisco
CORE-SW01# show vlan brief
```
*Expected Output:*
- `10 Student_Staff_Wi-Fi active`
- `20 Academic_Labs active`
- `30 Faculty_Admin active`
- `40 Data_Center active`
- `999 QUARANTINE_NATIVE active`

### 2. Verify 802.1Q Hardened Trunking:
```cisco
CORE-SW01# show interfaces trunk
```
*Expected Output:*
- Trunk mode: `on`
- Encapsulation: `802.1q`
- Native VLAN: `999` (Quarantine)
- Vlans allowed on trunk: `10,20,30,40,50,99`

### 3. Verify Spanning Tree Protocol (IEEE 802.1w Rapid-PVST+):
```cisco
CORE-SW01# show spanning-tree vlan 10
```
*Expected Output:*
- `Spanning tree enabled protocol rstp`
- `Root ID Priority: 4096`
- `This bridge is the root`

### 4. Verify SVI Default Gateways:
```cisco
CORE-SW01# show ip interface brief | include Vlan
```
*Expected Output:*
- `Vlan10   10.10.0.1    YES manual up up`
- `Vlan20   10.10.4.1    YES manual up up`
- `Vlan30   10.10.6.1    YES manual up up`
- `Vlan40   10.10.7.1    YES manual up up`

### 5. Verify OSPF Dynamic Routing Neighbor Adjacency:
```cisco
CORE-SW01# show ip ospf neighbor
```
*Expected Output:*
- Neighbor `10.255.255.254` (EDGE-RTR01) in state `FULL/DR` or `FULL/BDR`.

### 6. Verify IP Routing Table:
```cisco
CORE-SW01# show ip route
```
*Expected Output:*
- Connected routes (`C`) for each SVI subnet.
- OSPF routes (`O`) learned dynamically from the edge router.
- Gateway of last resort: `10.255.0.1` to network `0.0.0.0`.

## 4. End-to-End Connectivity Testing

1. Configure `PC0` connected to `ACC-BLD1` (VLAN 10):
   - IP Address: `10.10.0.50`
   - Subnet Mask: `255.255.252.0` (matching /22)
   - Default Gateway: `10.10.0.1`
2. Configure `PC1` connected to `ACC-BLD2` (VLAN 20):
   - IP Address: `10.10.4.50`
   - Subnet Mask: `255.255.254.0` (matching /23)
   - Default Gateway: `10.10.4.1`
3. Open `PC0` Desktop &rarr; Command Prompt and run:
   ```cmd
   ping 10.10.0.1      # Tests local SVI default gateway
   ping 10.10.4.50     # Tests inter-VLAN routing across Core switch
   ping 10.255.0.1     # Tests transit uplink to Edge router
   ```
4. All ICMP echo replies will return with `0% packet loss` (after initial ARP resolution), confirming that the NetArchitect generated configurations operate flawlessly in Cisco Packet Tracer.
